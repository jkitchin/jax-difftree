~difftree~ trains soft, oblique-split decision trees end to end with gradient
descent in JAX, behind scikit-learn compatible estimators. Each leaf holds a
Gaussian (or a multivariate Gaussian for multi-output targets), so the
prediction at every input is a mixture of Gaussians weighted by soft path
probabilities. That gives you a calibrated predictive variance, split into
within-leaf (aleatoric) and between-leaf (routing) parts. For multi-output
targets it also gives closed-form conditioning on observed outputs and
gradient-based inverse design.

For surrogate optimization, trees can have affine leaves trained with
optional Jacobian matching. A trained tree can be hardened into a crisp
piecewise-affine model and exported as leaf polytopes or as a JSON spec for
exact embedding in a mixed-integer linear program.

* Features

- Heteroscedastic regression with predictive std, quantiles, samples, and an aleatoric/routing variance decomposition
- Multivariate Gaussian leaves with full predictive covariance, closed-form conditionals p(y_unobs | x, y_obs), and conditional sampling
- Inverse design: multi-start gradient ascent on log p(y_target | x) with partial targets and box bounds
- Classification with an aleatoric/epistemic entropy decomposition
- Post-hoc calibration of split steepness and variance scale on a held-out slice
- Affine leaves, Jacobian (Sobolev) training, crisp hardening, and optional continuity across splits
- MILP export as leaf polytopes or a jax-ldt JSON spec, plus tools to measure boundary jumps and repair MILP solutions

* Quickstart

#+begin_src python
from difftree import DifferentiableTreeRegressor
from sklearn.datasets import make_friedman1
from sklearn.model_selection import train_test_split

X, y = make_friedman1(n_samples=600, noise=1.0, random_state=0)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=100, random_state=0)

model = DifferentiableTreeRegressor(depth=5, n_epochs=150, random_state=0)
model.fit(X_tr, y_tr)

mean, std = model.predict(X_te, return_std=True)
mean, std, std_aleatoric, std_routing = model.predict(X_te, return_components=True)
q05, q50, q95 = model.predict_quantile(X_te, q=[0.05, 0.5, 0.95])
#+end_src

See the [[https://jkitchin.github.io/jax-difftree/quickstart.html][quickstart]] for multivariate regression, inverse design, and
classification, and [[https://jkitchin.github.io/jax-difftree/surrogates.html][surrogates for MILP embedding]] for affine leaves,
hardening, and export.

* Related work

The approach is closest to the end-to-end decision trees of Hehn, Kooij, and
Hamprecht ([[https://doi.org/10.1007/s11263-019-01237-6][IJCV 2020]]), but keeps splits finitely soft at test time so that
routing uncertainty contributes to the predictive variance. See the [[https://jkitchin.github.io/jax-difftree/background.html][background]]
and [[https://jkitchin.github.io/jax-difftree/references.html][references]] pages for more.
